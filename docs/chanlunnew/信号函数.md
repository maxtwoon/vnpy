# 信号分类

---

信号函数的作用主要有两种：1）决定什么时候进行开平仓、加减仓等操作，这类信号称之为“**仓位调整**”信号；2）根据当下市场状态进行完全分类，这类信号称之为“**完全分类**”信号。需要注意的是，部分信号函数通过调整参数既可以用作仓位调整，也可以进行完全分类。

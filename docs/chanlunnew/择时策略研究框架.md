# 一、事件描述：Signal \- Factor \- Event



`Signal`是最基础的表达，可以用字符串`k1_k2_k3``_``v1_v2_v3``_``score`表示, 其中：

- k1\_k2\_k3 是信号名称；

- v1\_v2\_v3 表示信号值；

- score 是一个信号打分值（推荐 0\~100 之间），这是预留的设计，暂时没有用上。



`Factor`是`Signal`的组合，支持`all | not | any`三种逻辑关系进行组合。



`Event`是`Signal`和`Factor`的组合，同时指定`Operate`，表示一个具有明确信息的操作事件。



**关于这个描述体系的详细了解，建议阅读以下源码中相关对象：**

- https://github\.com/waditu/czsc/blob/a77a480455a33282551b753913f1c65da7eeb655/czsc/objects\.py\#L366



信号字典是`Signal - Factor - Event`的输入，一个典型信号字典如下，信号字典的 key 是 signal 的 key，信号字典的 value 是 signal 的 value \+ score 部分：

```Python

             ('15分钟_倒0笔_长度', '大于5_其他_其他_0'),

```

# 二、持仓子策略：Position



Position 表示持仓对象，其实是一个独立的子策略，为了便于表达后续将这个对象的实例都称为“**持仓策略**”或者“子策略”。**实例化一个持仓策略至少需要传入：1）交易品种；2）开仓事件列表。**当然，也可以传入指定的平仓事件列表和一些配置参数。支持的参数描述如下：

```Python
class Position:
    def __init__(self, symbol: str, opens: List[Event], exits: List[Event] = None, interval: int = 0,
                 timeout: int = 1000, stop_loss=1000, T0: bool = False, name=None):
        """简单持仓对象，仓位表达：1 持有多头，-1 持有空头，0 空仓

        :param symbol: 标的代码
        :param opens: 开仓交易事件列表
        :param exits: 平仓交易事件列表，允许为空
        :param interval: 同类型开仓间隔时间，单位：秒；默认值为 0，表示同类型开仓间隔没有约束
                假设上次开仓为多头，那么下一次多头开仓时间必须大于 上次开仓时间 + interval；空头也是如此。
        :param timeout: 最大允许持仓K线数量限制为最近一个开仓事件触发后的 timeout 根基础周期K线
        :param stop_loss: 最大允许亏损比例，单位：BP， 1BP = 0.01%；成本的计算以最近一个开仓事件触发价格为准
        :param T0: 是否允许T0交易，默认为 False 表示不允许T0交易
        :param name: 仓位名称，默认值为第一个开仓事件的名称
        """
```



下面，我们创建一个只有日线第一买卖点开仓的持仓策略。由于只传入了开仓事件列表，那么出场就是靠默认的 止损 和 超时 两种，分别由 stop\_loss 和 timeout 两个参数控制。

```Python
from czsc import Position, Signal, Factor, Event, Operate

opens = [
    Event(name='开多', operate=Operate.LO, factors=[
        Factor(name="日线一买", signals_all=[
            Signal("日线_D1B_BUY1_一买_任意_任意_0"),
        ])
    ]),
    Event(name='开空', operate=Operate.SO, factors=[
        Factor(name="日线一卖", signals_all=[
            Signal("日线_D1B_BUY1_一卖_任意_任意_0"),
        ])
    ]),
]

pos = Position(name="持仓策略样例1", symbol="000001.SH", opens=opens)
```



为了更明确的定义止损和超时出场的参数，修改上面的持仓策略如下：

**注意：**

1. stop\_loss 参数对应的单位是 BP，下面设定的 500 BP 表示亏损超过 5% 止损

2. timeout 参数对应的单位是基础周期K线，下面设定的 1000 表示超过 1000根基础周期K线没有信号就出场

```Python
from czsc import Position, Signal, Factor, Event, Operate

opens = [
    Event(name='开多', operate=Operate.LO, factors=[
        Factor(name="日线一买", signals_all=[
            Signal("日线_D1B_BUY1_一买_任意_任意_0"),
        ])
    ]),
    Event(name='开空', operate=Operate.SO, factors=[
        Factor(name="日线一卖", signals_all=[
            Signal("日线_D1B_BUY1_一卖_任意_任意_0"),
        ])
    ]),
]

pos = Position(name="持仓策略样例1", symbol="000001.SH", opens=opens, stop_loss=500, timeout=1000)
```





# 三、策略基类：CzscStrategyBase



择时交易策略的编写需要继承 `CzscStrategyBase`，在这个基类中实现了一些基本的方法。

**择时交易策略的两个要素：**
1\. 交易品种以及该品种对应的参数
2\. 持仓策略列表



**Note: 从 0\.9\.15 版本开始，策略的实现只需要编写 postions 属性**



实现一个策略需要继承`CzscStrategyBase`，然后实现持仓策略列表 positions 属性。一个样例策略如下：

```Python
import czsc
from czsc import Event, Position


def create_beta_long_V230406(symbol, **kwargs):

    - https://czsc.readthedocs.io/en/latest/api/czsc.signals.bar_zdt_V230331.html

    :param symbol:
    :return:

        {'name': '开多',
         'operate': '开多',
         'signals_all': [],
         'signals_any': [],
         'signals_not': [],

                      'signals_all': ['15分钟_D1SMA#34_BS3辅助V230319_三买_任意_任意_0'],
                      'signals_any': [],
                      'signals_not': []}
                     ]},
    ]

    exits = [
        {'name': '平多',
         'operate': '平多',
         'signals_all': [],
         'signals_any': [],
         'signals_not': [],

                      'signals_all': ['日线_D1T10_状态_阴线_长实体_任意_0'],
                      'signals_any': [],
                      'signals_not': []}]},

    ]
    if kwargs.get('is_stocks', False):
        opens[0]['signals_not'].append('15分钟_D1_涨跌停V230331_涨停_任意_任意_0')
        exits[0]['signals_not'].append('15分钟_D1_涨跌停V230331_跌停_任意_任意_0')

                   opens=[Event.load(x) for x in opens],

        {'name': '平多',
         'operate': '平多',

class CzscStocksBeta(czsc.CzscStrategyBase):
    """CZSC 股票 Beta 策略"""

    def __init__(self, **kwargs):
```

# 四、CzscTrader 批量执行N个持仓策略



`CzscTrader`是缠中说禅技术分析理论之多级别联立交易决策类*，*策略执行的核心类。在策略基类中已经实现了输入K线初始化`CzscTrader`对象的方法。



```Python
from czsc.strategies import CzscStrategyExample2
from czsc.data.ts_cache import TsDataCache


dc = TsDataCache(r'C:\ts_data', sdt='2010-01-01', edt='20211209')

# 获取K线数据，这里使用的是tushare的数据，也可以使用其他数据源。必须返回 RawBar 对象的列表
symbol = '000001.SZ'
bars = dc.pro_bar_minutes(ts_code=symbol, asset='E', freq='15min',
                          sdt='20151101', edt='20210101', adj='hfq', raw_bar=True)

# 实例化策略对象，这里使用的是 CzscStocksBeta 策略，也可以使用其他策略
tactic = CzscStocksBeta(symbol=symbol)

# 调用策略对象的 init_trader 方法，传入K线数据，获取 CzscTrader 对象实例
# sdt = '20200801' 表示从 2020-08-01 开始回测，在这个时候之后的交易会被记录在持仓对象中
trader = tactic.init_trader(bars, sdt='20200801')

# 查看所有持仓策略的交易绩效
for pos in trader.positions:
    print(pos.name, pos.evaluate(trade_dir='多空'))

# 也可以调用策略基类中 replay 方法执行策略回放，查看策略交易的HTML快照
trader = tactic.replay(bars, res_path=r"C:\ts_data_czsc\trade_replay_test_c", sdt='20170101', refresh=True)
print(trader.positions[0].evaluate_pairs())
```







# 五、使用 DummyBacktest 进行择时策略快速迭代开发

---

**DummyBacktest 是 0\.9\.13 版本之后的新增功能**，策略快速迭代的原理是：**信号生成与持仓策略回测分离**，也就是说一批信号生成之后可以多次重复使用，前提是新编写的持仓策略没有使用缓存信号文件中不存在的信号。同时，DummyBacktest 支持多进程执行。



**特别注意：**由于跟持仓相关的信号依赖底层策略，所以用DummyBacktest回测的策略不能使用这类信号。



```Python
import czsc
from czsc.connectors import qmt_connector as qmc
from czsc.strategies import CzscStrategyExample2


dummy = czsc.DummyBacktest(strategy=CzscStocksBeta, read_bars=qmc.get_raw_bars, sdt='20200101', edt='20230301',
                           signals_path=r'D:\QMT投研\CzscStocksBeta\signals',
                           results_path=r'D:\QMT投研\CzscStocksBeta\results_20200101_20230301')

# # 查看某个品种的交易回放
# dummy.replay('000001.SZ')


# Python中的多进程必须在if __name__ == '__main__'中执行，否则会报错

if __name__ == '__main__':
    # 定义需要回测的品种，这里可以自定义
    symbols = qmc.get_symbols('train')
    # 这里仅回测前10个品种，作为执行示例
    dummy.execute(symbols[:10], n_jobs=4)
```

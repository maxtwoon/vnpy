# A106 走势类型分类信号（盘整 / 趋势）设计

- 任务：A106
- 阶段：design
- 日期：2026-07-29
- 依据：`docs/theory_code_crosscheck.md` §2（走势类型，书第 75~79 页）、§9 P1 项
- 铁律：信号为**新增只读分类**，默认不接入任何开/平仓逻辑，不改动现有信号、参数与回测基线。

## 1. 背景与目标

《缠论》把"含中枢的运动"分为两类走势类型（书第 77 页）：

- **盘整走势类型**：只含一个该级别中枢，标准模型 a + A + b；
- **趋势走势类型**：含两个及以上同级别、同方向且依次（上涨抬高 / 下跌降低）的中枢，
  且**任何相邻两个中枢的构成部分无任何接触/重叠**（书第 78 页——趋势区别于盘整延伸的关键判据）。

项目现状（对照核查表 §2）：`czsc_adapter.get_trend_type()` 是按最近 3 笔方向的启发式，
不在主信号链路；主链路 `chan_strategy/` 无走势类型分类。本任务在主链路新增一个确定性信号，
输出当前结构的走势类型分类。所有中枢均为**笔中枢**（见 §8 探针结论），信号与文档必须沿用此口径。

## 2. 信号契约

- **信号名**：`{freq}_D1ZS_走势类型V260729`（沿用 `D1ZS` 家族命名与版本日期后缀）。
- **完全分类**（v1，互斥且穷尽）：

| v1 | 判据 |
|----|------|
| `无中枢` | 已确认笔构建不出任何中枢，或笔数不足（< 5） |
| `盘整` | 恰好 1 个中枢（a + A + b 模型） |
| `上涨趋势` | ≥ 2 个中枢，且全部相邻中枢依次**抬高**且**无重叠** |
| `下跌趋势` | ≥ 2 个中枢，且全部相邻中枢依次**降低**且**无重叠** |
| `中枢延伸` | ≥ 2 个中枢，但存在相邻中枢重叠，或抬/降方向不一致——即书第 78 页"不构成趋势"的情形 |

- **输出格式**：`f"{v1}_任意_任意_{score}"`（与现有 D1ZS/D1BSP 信号一致）；
  score 建议：无中枢 0 / 盘整 50 / 中枢延伸 60 / 趋势 80（仅排序用，无交易含义）。

## 3. 关键判据定义（设计决策，dev 不得静默更改）

- **D1 中枢来源**：复用 `chan_strategy.zhongshu.build_zhongshu_from_bis()` 输出
  （含 zg/zd/gg/dd 与起止索引），输入为 `_get_confirmed_bi_list()` 的**已确认笔**，
  与一买/三买等信号同一口径，杜绝未来函数。
- **D2 "依次抬高"**：对相邻中枢 i、i+1，`zd[i+1] > zd[i]` 且 `zg[i+1] > zg[i]`；
  "依次降低"镜像。所有相邻对都必须满足，否则归 `中枢延伸`。
- **D3 "无重叠"**：相邻中枢区间 `[zd, zg]` 不相交，即 `zg[i] < zd[i+1]`（上涨）或
  `zd[i] > zg[i+1]`（下跌）。取 zg/zd 而非 gg/dd 的理由：书上"构成部分无接触"指中枢区间
  本身；gg/dd 是构成笔的极值波动，作为更严判据会过度收缩。gg/dd 口径留作后续可加严的选项，
  本版固定 zg/zd，写入 docstring。
- **D4 趋势方向与 a0**：本版方向完全由中枢序列几何决定（D2），不引入进入段 a0 方向校验；
  书第 79 页"方向由进入段决定"与本几何判据在正常结构下结论一致，差异情形（罕见）记入决策记录，
  若 review 要求可后续补 a0 校验门。
- **D5 级别口径**：本信号在单一 K 线周期的笔中枢上计算，分类结果仅为该观察窗口下的结构分类；
  信号键名携带 freq 是工程标记，不得表述为递归级别（对照核查表 §3.1）。docstring 必须写明。

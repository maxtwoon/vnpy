中枢的方向（书第66页）：中枢本质上没有方向，方向是被赋予的。形成中的中枢（尚未出现第三类买卖点、处于暂定期）暂用进入段方向来确定方向。这与 2.7"走势方向由进入段 a0 决定"一致。笔中枢 vs 线段中枢（书第70页，必须分清）：
由笔构筑的中枢叫"笔中枢"；
由线段构筑的中枢叫"线段中枢"，即"最低级别走势类型中枢"；
两者级别完全不同：笔中枢是线段的组成部分，线段中枢是最低走势类型的组成部分。
书第76页进一步明确：走势连最小中枢都找不到 → 只能是笔；走势只由笔构筑 → 只能是线段；走势包含由线段所构筑的中枢 → 才能定义为最低级别走势类型。

LLM 核对要点：czsc 的 ZS 对象默认是笔中枢（因 czsc 以笔为 a0）。要得到书意义上的"走势类型中枢"，需在线段层面识别。报告中必须注明所报中枢是"笔中枢"还是"线段中枢"，绝不可混称。ZS 字段含 zg/zd/gg/dd/bis。
2.7 走势类型（书第75~79页）
走势是对一个向上或向下运动的分类，划分必须含"级别"概念。任何包含中枢的运动都可定义为某一级别的走势。（书第76页）
走势类型的组件 = 线段（次级别走势类型）+ 中枢个数。（书第76页）
按中枢数量分两大类（书第77页）：

盘整走势类型：只含一个该级别中枢。标准模型 a + A + b。
趋势走势类型：含两个及以上同级别、同方向且依次（上涨抬高/下跌降低）的中枢，且任何相邻两个中枢的构成部分无任何接触/重叠（书第78页，这是趋势区别于盘整延伸的关键判据）。标准模型 a + A + b + B + c（a=进入段，b=连接段，c=离开段；c 段一般作为可能的背驰段，书第79页）。

方向（书第79页）：由进入段 a0 方向决定。a0 向上 → 向上走势类型（趋势或盘整）；a0 向下 → 向下走势类型。趋势再据此分上涨/下跌。
2.8 级别（书第81~94页）
级别 = 缠论走势中的计量单位，有进制、可相互转换替代（书第81页）。
走势类型的级别 = 它所包含的最大中枢级别来定义，而不是由中枢数量定义（书第80页）。同级别的盘整与趋势走势类型，不能认为盘整就小于趋势。
级别晋升链（书第82页表3-1）：1分钟笔（毫克）→ 1分钟线段（克）→ 1分钟标准走势类型（千克）。即：笔→线段是一次晋级，线段→最低走势类型是又一次晋级。
级别递归生长（书第93页）：三个 1 分钟走势类型重叠 → 构成 5 分钟中枢 → 定义 5 分钟走势类型；三个 5 分钟走势类型重叠 → 30 分钟走势类型……层层递归。
级别 ≠ 时间周期（书第83~84页）：1/5/30 分钟只是常用标记，实际是"无级"的；同一段走势在不同周期图上是同一段，只是计量精度不同。时间周期只是观察窗口，级别由递归结构决定。
2.9 背驰（书第97~103页）
定义（书第97页）：背驰是力量衰竭的表现，体现动力学。衰竭与否需"比较而得"，先解决"谁和谁比"。
中枢引力（书第97页）：中枢对进入段与离开段有相同引力；构件越多、能量越大；脱离中枢需要的能量越大。比较离开段与进入段，即可判断离开段能否真正离开。
三种判断方法：

MACD 红绿柱面积（书第99页）：比较中枢进入段与离开段的 MACD 柱面积，离开段面积更小 → 背驰。实战技巧：离开段当下红柱面积 ×2 仍小于进入段面积，可暂定背驰。
中枢进入段与离开段的高度/空间（书第100页，离开段需确认完成）：离开段运行高度 h₂ < 进入段高度 h₁ → 背驰。
动能公式（书第101页）：一段走势的动能 = 运动空间 / 走势级别。比较同级别同性质两段。

背驰使用要点（书第102~103页）：

背驰段不意味着必然背驰，c 段只是"可能背驰"；
c 段无论背驰与否，仍可生成中枢 C、d 段（类似火箭第二、三级助推器）；
真正意义上的背驰是"区间套下的结构完成"，单一级别下的动能比较只能是辅助手段（书第103页）。这是 LLM 判断背驰时的主干逻辑：背驰判断必须落到多级别联立（区间套），MACD/高度/动能比较是平面快速辅助手段。

2.10 三类买卖点（书第113~119页）—— 核心交易决策买卖点是缠论特有的客观操作依据，源于分析逻辑的客观性，必须标注级别（书第116页："买卖点一定要加级别，要表达清楚是什么级别下、什么走势的一买一卖"）。

买卖点定义（严格按书）关键条件第一类买卖点（1B/1S）某级别走势完成、且伴随力量衰竭（背驰）时所对应的顶底分型，由背驰引发（书第113~114页）① 某级别走势完成（背驰只在中枢进入段/离开段间比较产生，故载体通常为已完成的趋势走势类型）；② 由背驰引发；③ 必然对应顶/底分型；④ 一买/一卖与前一走势的完成是"一体两定义"第二类买卖点（2B/2S）第一类买卖点之后，次级别回抽不创新低（买）/不创新高（卖）所形成的点（书第116页）对 1B/1S 的确认；本质是次级别的第一类买卖点第三类买卖点（3B/3S）某次级别走势类型脱离本级别中枢后，回抽未回到原中枢区间内所形成的点（书第117页）买点：回抽低点 > 中枢 ZG；卖点：回抽高点 < 中枢 ZD。同时证明该中枢已构筑完成（书第118页）；本质是次级别的第一类买卖点
第三类买卖点在 czsc 中表现为特定的五笔/七笔/九笔形态，传入 K 线后由对应的多笔形态信号计算得出。读取 CZSC.signals 中倒1/倒2 的多笔形态信号即可定性（信号键名以所用 czsc 版本为准）。
2.11 区间套（书第104~110页）
定义：区间套是多级别联立的通用方法。只要观察段不是最低级别（最好保证有三级及以上走势），即使在中枢内运行依然可行（书第109页）。
作用：用大级别确定方向与背驰，递归用次级别背驰精确定位买卖点，把买卖点从"一个区域"收窄到"一个点"。
递归与区间套是一来一往（书第112页）：

递归：描述走势如何从小到大生长（1分钟→5分钟→30分钟→日线）；
区间套：观察走势如何从大到小终结（日线→30分钟→5分钟→1分钟）。
两者一体两面，实操中需同时考虑。

2.12 结合律与多义性（书第134~138页）—— 保证客观性的铁律
结合律（书第135页）：缠论的走势组件可在遵守结构自同构的前提下重新拆分组合，组件不被重复使用。
多义性（书第138页）：任何一段走势都可有多种释义，遵循结合律时走势组件能随意拆分与组合，不同组合得出不同走势定义，但买卖点是"变换不变性"的——无论如何组合，买点依然是买点、卖点依然是卖点。这就是缠论的客观性。
示例（书第137页图3-104）：同一走势 0-9 可在 5 处划分为"下跌+上涨"，也可把中枢 3-4 与 6-7 结合为中枢 A（0-3 为进入段、7-9 为离开段），两种划分下 8 都是第三类买点。

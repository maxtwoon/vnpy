## 术语短句素材
> 显著词只作为风格线索，实际写作优先使用这些短句素材。

- 1F [数据降级] → 1F结构只适合细化入场节奏，不替代日线结论
- 1分钟 [数据降级] → 1分钟结构只适合细化入场节奏，不替代日线结论
- 30F [数据降级] → 30F结构用于连接日线判断与短线节奏
- 30分钟 [数据降级] → 若有30分钟数据，应优先用其确认次级别节奏
- 5F [数据降级] → 5F结构用于观察短线承接和回抽质量
- 5分钟 [数据降级] → 若有5分钟数据，应优先用其观察盘中回抽和离开力度
- 中枢构建 [结构解释] → 中枢构建阶段以震荡和边界确认优先
- 分型 [结构解释] → 分型只是转折苗头，仍需后续笔确认
- 底分型 [结构解释] → 底分型出现后，短线修复仍需要后续笔确认
- 强调整 [风险提醒] → 强调整说明回落仍有承接，重点看是否守住关键下沿
- 承接 [风险提醒] → 承接是否有效，要看回落时能否守住中枢或前低区域
- 推演 [情景推演] → 当前更适合做情景推演，而不是给单一路径结论
- 日线 [数据降级] → 日线结构决定主要观察框架，次级别只负责细化节奏
- 月线 [数据降级] → 更高级别背景只作方向约束，当前操作仍以本级别结构为准
- 温和 [风险提醒] → 走势相对温和时，边界得失比单日涨跌更重要
- 盘整 [结构解释] → 盘整结构里更重视上下沿得失，而不是追逐单根K线
- 离开段 [结构解释] → 当前处在离开中枢后的力度观察阶段，重点看离开段是否有持续性
- 第一种 [情景推演] → 第一种情景通常对应向上修复或突破延续，需要观察关键位能否站稳
- 第三种 [情景推演] → 第三种情景通常对应中枢内反复震荡，等待方向重新选择
- 第二种 [情景推演] → 第二种情景通常对应回落确认或结构降级，需要观察下沿是否失守
- 线段 [结构解释] → 线段级别的延续或转折，需要结合下一笔确认
- 缺口 [量能/板块人工确认] → 缺口属于情绪与强弱辅助信号，需要结合是否回补判断
- 背驰 [风险提醒] → 背驰出现后不要急于下结论，重点观察确认笔和反向力度
- 走势类型 [结构解释] → 走势类型尚需通过后续离开与回抽来确认级别
- 趋势 [结构解释] → 趋势延续需要新的离开段力度配合，否则容易回到中枢震荡
- 进入段 [结构解释] → 当前更像进入中枢后的再选择，不能简单按单边趋势处理
- 量能 [量能/板块人工确认] → 量能变化需要单独核验，若无量能配合则降低突破预期
- 顶分型 [风险提醒] → 顶分型出现后，短线压力仍需要后续笔确认

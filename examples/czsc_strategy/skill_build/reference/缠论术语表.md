# 缠论术语 ↔ 代码信号 映射表

> 双向对照：解盘话术 ↔ `analyze_symbol.py` 输出字段。
> 含跨品种通用性标注（结构层通用；量能/板块/缺口为 A 股语境，期货慎用）。
> 各状态下的"高频/显著话术"由 `build_mapping.py` 的 `mapping.md` 自动补充，本表为人工骨架。

## 方向 (D1BI_方向)
- 向上 → "向上一笔延续中""多头态势"  | 通用
- 向下 → "新向下一笔""调整中"        | 通用
- 无有效笔 → "结构未成型，观察"       | 通用

## 中枢位置 (D1ZS_位置)
- 中枢上方 → "站上中枢，偏强""5F中枢上方运行" | 通用
- 中枢内 → "中枢震荡""高位消化"               | 通用
- 中枢下方 → "跌破中枢，转弱"                  | 通用
- 无中枢 → "中枢未形成"                        | 通用

## 数据状态 (D1ZS_数据状态)
- 充分 / 不足 → 不足时解盘应降级为"结构样本不足，暂不下买卖点结论" | 通用

## 背驰 (D1BI_背驰)
- 疑似 → "小背驰状态""背驰苗头"   | 通用
- 失效 → "背驰失效，继续创新低/高" | 通用
- 无 → （不强调）                  | 通用

## 结构状态 (D1ZS_结构状态)
- 已确认 → "中枢已成立"  | 通用
- 未确认 → "中枢初见模型，构建中" | 通用

## 买点 (一买/二买/三买)
- 一买确认 → "底背驰一买"           | 通用
- 二买确认 → "回抽不破前低，二买"   | 通用
- 三买确认 → "对前面中枢构成 3 买" | 通用
- 候选/阶段态 → "等待买点确认"      | 通用

## 卖点 (一卖/二卖/三卖)
- 一卖确认 → "顶背驰一卖"           | 通用
- 二卖确认 → "反抽不破前高，二卖"   | 通用
- 三卖确认 → "对前面中枢构成 3 卖" | 通用

## 风控 (多头风控/空头风控)
- 结构失效 → "跌破中枢下沿/突破中枢上沿，结构破坏" | 通用
- 震荡超限 → "中枢内反复，方向不明"               | 通用

## A 股语境维度（期货不直接适用，需人工确认）
- 量能 / 承接 / 板块轮动 / 缺口：代码不产出，解盘如引用须标注"需人工确认"。

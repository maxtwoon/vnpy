# 解盘输出模板（五段式）

> 源自语料范式。所有结构判断引自 analyze_symbol.py 的 JSON；价位必须可追溯到中枢/笔端点。
> 分钟级不可用时，第二段按"降级写法"处理，禁止硬凑次级别推演。

```
【<标的> 缠论解盘 · <asof>】

一、日线结构
   方向=<方向>，<中枢位置>；中枢 ZG=<zg> ZD=<zd>（<n_bis>笔）。
   <处于上攻/调整；若有背驰则点出；调整深度强弱>。

二、次级别推演
   - 若 minute_available=true：
     <30分钟/5分钟 中枢构建、进入段vs离开段、背驰状态>。
   - 若 minute_available=false：
     "次级别数据不可用，本段略；以下推演基于日线结构。"

三、买卖点状态
   多头：一买=<>｜二买=<>｜三买=<>
   空头：一卖=<>｜二卖=<>｜三卖=<>
   <对当前最相关的那个买卖点给出结构依据>。

四、强弱判断
   <基于背驰/结构状态/中枢位置的强弱；量能/板块如无数据标注"需人工确认">。

五、后续推演（2–3 种情景）
   第一种：<守住/突破 某关键价位> → <含义，引对应买卖点>。
   第二种：<跌破/回落 某关键价位> → <含义>。
   （可选第三种）
   每个分支的触发价位必须来自客观 ZG/ZD/前高前低。

免责声明：以上为缠论结构分析与推演，不构成投资建议。
```

## 降级规则
- 数据状态=不足 → 全文降级："结构样本不足，仅描述现状，不下买卖点结论"。
- minute_available=false → 第二段用降级写法。
- 无中枢 → 跳过中枢相关价位，只描述笔方向与分型。

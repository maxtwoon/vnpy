# 缠论走势解盘 (Chan Pan Analysis)

> 草案骨架。`reference/` 与 `scripts/` 在数据管线(corpus_cleaner → fetch_sh_index_daily → build_mapping)
> 跑通后填充。本文件定位、工作流、约束已定，内容随映射表产出而充实。

## 何时使用

用户要求对某标的做缠论走势分析 / 盘后解盘 / 当前买卖点判断 / 结构推演时。
支持两种模式：
- **单标的按需**：分析指定标的"当下"走势。
- **批量盘后**：对一组标的逐个出解盘（可挂定时任务，收盘后自动跑）。

## 铁律（先读）

1. **结构判断必须来自客观计算**：方向、中枢(ZG/ZD)、背驰、买卖点状态、关键价位，
   一律取自 `scripts/analyze_symbol.py` 的输出 JSON，**不得凭空编造**，关键价位必须能追溯到代码算出的笔端点/中枢边界。
2. **只用已确认结构**：复用 `_get_confirmed_bi_list`（已剔除延伸末笔），避免未来函数/重绘。
3. **代码算不出的维度（量能、板块轮动、缺口情绪）**：要么省略，要么标注"需人工确认"，不得编造。
4. **必须带免责声明**：本输出是结构分析与教育性推演，不构成投资建议。
5. **不确定就说不确定**：数据不足/日线笔不够时，明确输出降级结论，不强行下判断。
6. **分钟级不可用时必须降级**：当 `minute_available=false`，第二段"次级别推演"写成
   "次级别数据不可用，本段略"，严禁用日线信息硬凑出分钟级中枢/背驰推演。
7. **预期态不是确认态**：`provisional_context` 只描述最新收盘价相对已确认中枢的位置，
   可以辅助情景推演，不能当成确认买卖点证据。
8. **观察点独立呈现**：`watch_points` 是后续触发/失效条件，必须和已确认一二三买卖点区分。
9. **先识别级别再判断分歧**：原文若混合日线、1分钟、5分钟、30分钟观点，
   先判断方向词属于哪个级别，避免把次级别调整误判成日线结构矛盾。
10. **日线级二买/二卖保守处理**：当前日线语料与日线客观信号中，二买/二卖缺少有效确认样本。
    日线级分析不主动给出二买/二卖确认话术；若 JSON 未明确给出确认，只能写成候选或观察条件。
    完整二买/二卖确认需要下沉到 30 分钟级并另行做语料对齐。
11. **优先使用语料术语**：能用缠论术语时，不泛化成普通金融话术。优先保留“离开段 / 进入段 / 回抽不入中枢 /
    中枢震荡 / 背驰 / 底分型 / 顶分型 / 强整理 / 温和调整”等历史语料高频表达。
12. **背驰必须显式表述**：即使客观 JSON 中 `背驰=无`，也要写一句“当前未见明显背驰”或“背驰信号不明显”，
    不要因为没有背驰就省略该结构要素。

## 工作流

1. 取参数：标的代码、级别（默认日线为主、次级别辅助）、截止日期（默认最新）。
2. 跑 `scripts/analyze_symbol.py <symbol>` → 得到多级别客观结构 JSON：
   各级别的 笔方向 / 中枢(ZG,ZD,笔数,位置) / 背驰 / 一二三买·一二三卖状态 / 数据状态 / 关键价位。
   指数模式可附加 `--minute-csv <minute.csv>`；近期分钟数据可用 `scripts/fetch_sh_index_minute.py` 抓取。
3. 读 `reference/signal_to_narrative.md`（组合句式、术语短句、状态→话术映射，由 build_mapping.py 产出；
   术语短句按角色使用，每类最多取一条）
   与 `reference/few_shot/*.md`（精选范例）。
4. 按 `reference/解盘模板.md` 的五段式组织输出，措辞对齐语料风格。

## 输出模板（五段式，源自语料范式）

```
【<标的> 缠论解盘 · <日期>】

一、日线结构
   <方向 / 中枢位置 / 当前处于调整或上攻 / 调整深度与强度>（引客观信号）

二、次级别推演
   - minute_available=true：<次级别中枢构建 / 进入段 vs 离开段 / 背驰状态>
   - minute_available=false：「次级别数据不可用，本段略；以下推演基于日线结构。」

三、买卖点状态
   <一二三买 / 一二三卖 的当前分类，及其结构依据>

四、强弱判断
   <结构强弱、背驰提示；量能/承接如无数据则标注需人工确认>

五、后续推演（2-3 种情景）
   第一种：<触发条件+关键价位> → <含义>
   第二种：<触发条件+关键价位> → <含义>
   （每个分支的价位必须来自客观 ZG/ZD/笔端点）

免责声明：以上为缠论结构分析与推演，不构成投资建议。
```

## 风格要点（从语料归纳）

- 先客观结构、后推演；多用"演绎/推演/第一种…第二种…"的情景式表达。
- 关键价位锚定中枢边界与前高前低；强弱用"强/正常/温和调整""背驰"等语料术语。
- 保持克制对冲语气，不下绝对结论。

## 资源

- `scripts/analyze_symbol.py`：多级别客观结构计算（复用 chan_strategy）。
- `scripts/fetch_sh_index_minute.py`：抓取近期上证指数分钟线，供实时/近期解盘补充次级别。
- `reference/缠论术语表.md`：术语 ↔ 代码信号双向映射。
- `reference/signal_to_narrative.md`：build_mapping.py 产出的组合句式、术语短句、状态→话术映射。
- `reference/解盘模板.md`：五段式骨架。
- `reference/few_shot/`：按形态精选的范例（一买/三卖/背驰/趋势/盘整各覆盖）。

## 已知边界

- 语料源为上证指数(A股)，结构层(笔/中枢/背驰/买卖点)跨品种通用；
  量能/板块/缺口等 A 股语境维度对期货不完全适用，术语表已标注。
- 分钟级历史有限：历史回测对照走日线级；分钟推演仅用于近期/实时。
- 30分钟级二买/二卖确认尚未完成两年语料对齐；日线 skill 只做保守观察。

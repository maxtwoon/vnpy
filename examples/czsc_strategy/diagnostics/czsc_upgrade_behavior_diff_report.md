# czsc 0.9.51 → 1.0.0rc8 行为差异报告

<!-- RESEARCH-ONLY / NOT PROMOTION EVIDENCE -->

本报告基于真实历史期货连续合约数据,量化 czsc 库从 0.9.51(纯 Python)升级到 1.0.0rc8(Rust 重写)后在分型、笔、中枢、买卖点信号层面的差异。
本报告仅供研究参考,不得作为策略有效性的推广证据。

## 数据与范围

- 数据来源: `2023-01-01` 至 `2025-12-31`
- 交易周期: 30分钟(30 分钟)
- 品种: A888, AP888, RB888, SC888, ZN888

- 新版本 fixture: `D:\repo\vnpy\examples\czsc_strategy\diagnostics\czsc_upgrade_fixtures\1_0_0rc8`
- 生成时间: 2026-07-28T10:03:33.044464
- 本次 fixture 使用的 ``CZSC_MAX_BI_NUM``: **10000** (环境变量 CZSC_MAX_BI_NUM=10000)

### 关于 ``max_bi_num`` 截断的披露

- 0.9.51 fixture 使用默认值 ``CZSC_MAX_BI_NUM=50``。
- 在独立探索性运行中将该环境变量设为 10000 时,0.9.51 返回了更多的笔 (见下表 `旧版未截断笔数`)。
- 1.0.0rc8 fixture 虽以 ``CZSC_MAX_BI_NUM=10000`` 启动,但实际 ``bi_list`` 仍只保留最近 50 笔,表明 Rust 核心在当前 RC 中似乎有独立的硬上限或尚未完整实现该环境变量。
- 因此下表 `笔 old/new` 与 `完全一致笔` 均基于两者**实际保留的相同 50 笔窗口**进行对比;未截断差异通过 `旧版未截断笔数` 一栏单独披露。

### ZN888 分型数量差异说明

ZN888 的 ``fx_count`` 从 0.9.51 的 222 上升到 1.0.0rc8 的 1074(约 4.8 倍),而 AP888/RB888/SC888/A888 的升幅明显更小。这并不意味着 ZN888 的缠论结构本身发生了数倍变化：按'至少是一个笔端点'的确认口径统计,ZN888 的确认分型数量与 A888/AP888 等品种处于同一量级(约 50 个)。ZN888 的高波动性/反复震荡产生了大量被后续 K 线否决的候选分型;1.0.0rc8 把这些候选保留在 ``fx_list`` 中,0.9.51 则提前过滤掉,于是呈现出 4.8 倍的计数差异。

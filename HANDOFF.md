## Goal

Make `backtest_matrix_report.py`'s `write_markdown` (and any other report generator found during
this task's own scan of `diagnostics/*.py` to have the same gap — check `run_position_sizing_
report.py` too, since it already threads `sizing_model` through as a possible reference for how
this codebase already handles the concept) emit its own `sizing_model`-aware caveat directly in
the generated report, not rely on post-hoc backfilling: when `sizing_model="research"`, the report
must prominently state that reported returns are percentage-based and NOT a real-capital P&L
curve; when `sizing_model="risk"`, state that lot counts/margin are real but still backtest-only,
not live-verified. Reuse `diagnostics.declassify_historical_reports.build_banner()` for the
RESEARCH-ONLY marker itself (the A56-fixed, A67-reused pattern) rather than inventing new banner
text. Read the current `sizing_model` from `STRATEGY_CONFIG` (already imported or importable) at
report-generation time.
